Test the ResQ web dashboard

Web Sign in

Use a laptop or desktop computer with Chrome, Edge, Safari or Firefox. The dashboard is built for big screens.

  1. Open the dashboard.
    Open ResQ Portal
    hospital-web-dashboard.vercel.app
  2. Sign in with the tester login we sent you in the group chat. Copy and paste the username and password to avoid typos. Everyone shares this login.
  3. You land on the Dashboard. Use the menu to move between pages.
Everyone shares one login, so please: Don't change the password, edit or delete accounts, or end other sessions in Settings. That would lock out every other tester. If you mistype the password five times, your computer is blocked for 15 minutes.

What to test

Try each area and note anything confusing, broken, or slow.

  1. Dashboard
    • Check the blood stock levels and the Stock Criticality alerts.
    • Look at Live Match Monitoring and Recent Arrivals.
  2. Broadcasts
    • Click New Broadcast and create a request: blood type, number of units, priority and ward.
    • Open View All Broadcasts. Requests marked Awaiting approval need a decision.
    • Approve one, and reject one with a reason.
    Approving sends a real notification to app testers with a matching blood type. That's expected; it's how we test alerts.
  3. Donor Management
    • Search for a donor by name, ID or phone, and try the filters.
    • Switch to Appointment View and move between days.
    • For an appointment, try Confirm Arrival and then Record Donation.
    • Try Add Manual Walk-in and Export CSV.
  4. Reports
    • Look through the charts: response time, fulfillment rate and demand forecast.
    • Use the filters, then try Export PDF.
  5. Settings
    • Look around Hospital Network, Inventory Thresholds and Red Cross Contact.
    • Account Credentials and team accounts: look only, don't change anything.
Everything in this beta is a test. The hospitals, blood requests and donors are test data, not real emergencies. Approve, reject, and record whatever you like outside of the account settings above.

If something goes wrong

"Too many failed login attempts"
Wait the number of minutes shown (up to 15), then paste the password again. If many testers mistype it, the login is blocked for everyone for 15 minutes.
The page is blank or stuck loading
The server may be waking up after being idle. Wait 30–60 seconds and refresh.
I was signed out
Someone may have ended sessions in Settings. Sign in again and let us know.
